# Skill images

Local SVG assets referenced by `src/data/about.json`. Import `src/data/about.ts`
in components to get URLs processed by Vite for development and production.

## Sources

- Most technology logos: https://github.com/devicons/devicon (MIT; see LICENSE-devicon.txt).
- TypeORM, OpenLayers, and Testing Library: https://github.com/simple-icons/simple-icons (CC0; see LICENSE-simple-icons.txt).
- Turf.js: https://github.com/Turfjs/turf-www/blob/master/static/img/logo.svg.
- Group icons and REST APIs: Font Awesome Free by Fonticons, Inc., https://fontawesome.com (CC BY 4.0; see LICENSE-fontawesome.txt). Exported from the installed package with a green fill.
- Vuex uses the Vue logo; React Native uses the React logo.

Brand marks belong to their respective owners. REST APIs uses a generic network
icon rather than a brand logo. No portrait is supplied; the profile retains its
initials fallback until a personal image is added.
